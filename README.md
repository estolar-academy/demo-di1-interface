# Demo – Desarrollo de Interfaces 1

## Objetivo

Mejorar una interfaz aplicando principios básicos de usabilidad y accesibilidad.

## Actividad

Modifica el archivo `index.html` y realiza estas tres mejoras:

1. Agrega una etiqueta `<label>` para el correo.
2. Cambia el input para utilizar `type="email"`.
3. Cambia el texto del botón `OK` por un texto más claro.

## Entrega

Realiza los cambios y crea un commit con el mensaje:

`Mejora de interfaz`

## Puntaje

- Label correctamente asociado: 3 puntos
- Input de tipo email: 3 puntos
- Texto claro en el botón: 3 puntos
- Commit correcto: 1 punto

Total: 10 puntos
